### Project Description

**CHAKKA-X** is an unnecessarily advanced simulation and investigation system built around one very important question:

> **“ചക്ക വീണു, മുയൽ ചത്തു. എങ്ങനെ?”**

The project lets users watch the incident, change parameters such as tree height, jackfruit weight, wind and rabbit position, simulate what happens to the rabbit, and finally investigate the root cause of the incident.

### The Problem (that doesn't exist)

A jackfruit fell from a tree and a rabbit was involved.

But an important question remains:

> **How much possibility was there for the rabbit to die?**

Was the chakka too heavy?  
Was the tree too tall?  
Was there wind?  
Could the rabbit escape?  
Why did the chakka fall in the first place?  
Was someone responsible?

These are questions that absolutely nobody needed answered.

### The Solution (that nobody asked for)

We built **CHAKKA-X**.

First, an animated cartoon shows the tragic incident. Then the user can modify the tree height, jackfruit weight, wind, rabbit distance, reaction time and other parameters.

The system simulates the incident and determines whether the rabbit:
- escaped
- survived
- was impacted
- or reached a fictional fatal outcome

After that, CHAKKA-X performs a complete root-cause investigation to determine **why the chakka fell and why the rabbit ended up in the wrong place at the wrong time.**

Because apparently one simulation wasn't enough, the project can also test multiple scenarios and alternate realities.
